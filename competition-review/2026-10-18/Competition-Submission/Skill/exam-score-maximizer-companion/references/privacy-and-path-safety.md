# Privacy and path safety

课程资料、试卷、姓名、学号、联系方式和作答记录默认留在用户授权的工作区。
不要把原文、绝对路径、个人标识或题目答案拼进 URL、查询参数、哈希、日志、
远程字体、CDN、分析脚本、iframe 或外部 API 请求。来源展示使用 `source_id`
和用户可读标签；只有用户明确选择联网查证时才讨论脱敏和范围。

## 文件规则

- 只读取用户明确提供的文件和当前任务工作区。
- 报告脚本必须接收一个授权工作区，并把输入/输出解析为工作区内相对路径。
- 拒绝绝对路径、空路径、`..` 路径段、目录作为文件、输入与输出相同。
- 解析真实路径后再检查是否仍位于工作区；拒绝越界符号链接/联接点。
- 默认不覆盖已有文件；覆盖必须由用户显式传入专用选项。
- 输入大小、JSON 类型、数字范围和日期格式先校验，再渲染或写入。
- 若输入字段名或文本疑似含姓名、学号、手机号等个人标识，脚本只输出一次不含原值的
  警告“输入含疑似个人标识字段，请确认已脱敏”；默认仅告警，不自动改写。
- 需要生成可分享副本时可显式传入 `--redact`；它只在报告载荷中替换疑似手机号、邮箱、
  身份证号和个人标识字段，不修改磁盘上的输入 JSON，并在标准错误输出替换数量。

## HTML 扫描

报告必须自包含，允许内嵌 CSS/JavaScript，禁止 `script src`、远程 `link`、
远程图片/字体、iframe/object/embed、fetch/XHR/WebSocket、分析或持久化存储。
用户内容先 HTML 转义；在脚本字符串中还要安全处理 `</script>`。
即使 JavaScript 失效，考试地图、今日任务、薄弱点和来源仍应可读。

## 降级

任何读取、校验、渲染或浏览器检查失败都保留同一份结构化内容并返回 Markdown，
同时列出失败检查和待补资料。静态扫描通过只证明文本和结构风险较低，不能代替
实际打开、移动端检查、作答回流或 TeleAgent 实机运行证据。
