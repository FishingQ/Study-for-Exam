# Provenance and adaptation notes

This Skill is a new implementation based on the team's `Study-for-Exam` workflow.
The following public projects were consulted for concepts and output contracts:

- [FishingQ/Study-for-Exam](https://github.com/FishingQ/Study-for-Exam): evidence-led exam map,
  paper-structure matching, major-question methods, feedback loop, and final sprint.
- [open-exam-skills](https://github.com/serenakeyitan/open-exam-skills): mind-map, flashcard,
  quiz, and study-pack separation. The repository declares MIT licensing.
- [examprep-ai](https://github.com/sickn33/agentic-awesome-skills/blob/main/skills/examprep-ai/SKILL.md):
  selective reading, difficulty bands, syllabus guardrails, and readiness framing.
- [agentic-exam-prep](https://github.com/evnchn-agentic/agentic-exam-prep): reasoning-quality
  triage, retest/revamp, and error-shape feedback. The repository declares MIT licensing.
- [study-system](https://github.com/SkillMedev/personal-operating-system/blob/main/skills/study-system/SKILL.md):
  active recall, spacing, interleaving, and error logs. The repository declares MIT licensing.
- [study-planner](https://github.com/blueqwertz/study-planner/blob/main/SKILL.md): marginal-utility
  ranking and time-budget variants. Its README states MIT, but the reviewed root did not expose
  a separate LICENSE file.

No external source text, code, frontend bundle, API key, or remote asset is required by this
package. Before copying any third-party implementation into a submission, recheck its license
and preserve required notices.
