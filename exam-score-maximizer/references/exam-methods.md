# 证据与题目规范

只为当前请求加载必要材料；先盘点文件，再按来源定位阅读，
大文件按目录/页码/时间戳分段，不要求全量塞入上下文。

## 首轮材料提交顺序

如果用户不知道先交什么，按“尽快抓住考试得分信息”的效率建议依次提交：老师最新划重点或变更说明、历年卷、课程大纲、课堂笔记。这个顺序是材料收集优先级，不替代证据强度判断；当前官方范围、教师直接纠正与新日期信息仍可推翻旧重点。材料可以是 PDF、照片或截图，不要求先手工转写；对模糊、裁切或 OCR 可疑的页码/字符标记待核对，并请用户补充原图或页码，不把不清楚的内容当成确认事实。

## 证据和冲突

教师录音、转写、直接纠正 → 官方卷型/当前大纲 → 教师划重点 →
历年卷/课堂例题 → 作业实验 → 教材与一般知识，是线索强度参考，
不是忽略新版本官方规定的理由。来源冲突记录日期、内容和影响；
保留原内容，向用户确认决定范围/分值的关键冲突。

| 字段 | 说明 |
|---|---|
| source_id | 固定标识；对应用户授权的来源标签 |
| locator | 页、节、题号、音频时间戳；未读到不能编造 |
| signal | 原话摘录或忠实摘要；OCR 可疑字符明确标注 |
| status | confirmed、high probability、supplementary、unknown |
| effect | 对范围、题型、分值、优先级的实际影响 |

confirmed：来源明确给出；high probability：多条独立证据支持但非确认；
supplementary：弱线索/补充练习；unknown：无依据。文件多次转载不算独立频次。
优先级 A 和 confirmed 不是同一维度：高收益任务可以仍是不确定预测。

没有真实材料时询问用户贴出/提供关键部分，先给不含虚构引用的临时计划；
科目通识可以标“通识补充，待课程资料核对”。不假装已读未收到的文件。
未知卷型时给练习集；假设卷必须列假设，不承诺完全匹配真实考试。

## 考试地图

覆盖矩阵：最小可测试知识点 → 可能题型 → 来源/等级 → 分值依据 →
答题动作 → 当前掌握证据 → 在哪套题覆盖。保留确认的题数、单题分值、
总分、考试时长、章节范围和排除项；局部未知不能全盘补齐为“确认”。
把“要会画/算/写程序”、长篇例题、教师明确大题与卷型交叉判断，
不把字号/红色文字本身当成大题证据。

## 初学者得分讲解

- 选择/判断：答案、考点、正确理由、典型干扰项和陷阱。
- 计算：已知、所求、公式适用条件、逐步代入、单位、结果合理性。
- 图形/波形：坐标和比例、关键点、变换顺序、标注与检查。
- 简答：定义、可检查得分点、联系/意义、精简回忆版。
- 材料/论述：所考理论、逐条材料证据、分析、结论；不整段堆理论。
- 编程/配置：拆分、完整代码/命令、预期结果、验证与常见失败。

官方评分细则存在则照其分配；没有则标“练习评分参考”，不能捏造教师给分。
大题给完整方法和变式；用户问“这一步怎么来的”时展开实际推导。
单步解释不足以满足“完整试卷/详解”的要求，按指定交付量生成完整内容。

## 多套模拟卷与还原

每次复用当前确认骨架和排除项；题数×单题分值求和检查。
变换数字、语境或组合，保留高权重点并补覆盖矩阵缺口，不用机械重复凑题。
教师口述还原题保留顺序和知识身份，创作数字/情景明确标“还原变式”。
讲解版每题答案后置紧随；闭卷版先题目、后答案册；HTML 折叠答案按需展开。
答案计算和选项下标需单独核对，引用正确不自动代表推导正确。
