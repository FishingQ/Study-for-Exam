# 时间与学习闭环

## 预期提分收益

目标是在学生的当前基础上得到可兑现的分数改善，考虑证据强度、题目权重、
未掌握缺口、可学会程度、时间成本和必要前置依赖。
已有可靠数字时可用“预期新增得分 ÷ 含前置学习的分钟数”做比较；
这些是规划估计，不是校准过的命中率/分数预测。没有数字时用理由和
A/B/C/D 档，不制造 0–100% 概率或任意风险乘数。

| 档 | 解释 |
|---|---|
| A | 可快速改善的大失分项/明确重点及必要前置；当前时间先做 |
| B | 完成 A 后投入的高收益步骤或变式 |
| C | 时间充足再做，投入更多但回报不确定 |
| D | 当前可略过；说清损失风险，不声称“保证不考” |

已掌握的高权重点可只短测验；基础概念缺口可能先修以解锁计算大题。
不要因为题目难就固定最后学，也不要让所有条目都成最高优先级。

## 可执行时间预算

区分距考试的自然时间与真正可学习的分钟。计划总量不超过后者，
每天不超用户给的上限；学习、复测、缓冲和安排在其中的休息均计入。
按实际余额动态缩减，适用 30 分钟、3 小时、6 小时、数日等，非固定 7 天。
已给预算就交一份实际能执行的计划；最低/现实/强化仅在用户需要比较时提供，
各方案均说明额外时间要求，不强塞三套冗长输出。

每块有 topic_id、动作、分钟、来源和可检查完成标准；
例如“闭卷写公式及条件后独立完成 2 个变式”，而非“看第 3 章”。
完成标准按本次范围和难度定义，不强制通用阈值。
剩余时间留给复测与缓冲；不存在适用于每个学生的固定 20%。
用户错题或未完成任务到来时重新分配剩余分钟，记录省略/替换原因。

## 主动回忆与错因

知识原子可被一道问答或一个关键得分步骤测试；一张卡不混多个独立事实。
先尝试回忆，再针对缺口简短学习并再测；不能让薄弱基础学生永远没机会
看必要讲解。程序/计算题可在掌握基本步骤后交错题型。

| 作答证据 | 下一步 |
|---|---|
| 正确且能给关键规则/步骤 | graduate：进入间隔复习，暂不等于稳定掌握 |
| 正确但猜/理由缺失 | retest：换题面测试同一知识点 |
| 错/误解/跳过 | revamp：定位错因，必要讲解后变式重练 |
| 方法正确但单位/格式错 | retest：加检查动作与得分步骤 |
| 来不及作答 | carryover：纳入下一次时间预算，不当概念错误 |

错因：概念缺失、条件混淆、计算/单位、误读、图形步骤、
遗漏得分点、代码/命令、记忆、未知。记录实际证据，不能仅按选项猜原因。
学生可以只写一句所用规则，不要求提供完整内部思考。
0–3 自评作为辅助：0 不会开始、1 认得但复现不了、2 提示后完成、
3 独立解决和解释。自评不是实际掌握证据。

复测日期需真实落在考试前可用窗口；例示 1/3/7/16/35 天是可选，
不是必须使用。考前 48 小时可用当日稍后和次日检查；
已毕业卡在间隔重现时失败则回到 retest/revamp，连续独立变式与间隔成功
才支持“较稳定”，仍不保证考试表现。

## 最后 48 小时

压缩已确认资料：大题方法/得分点、公式条件、常错单位符号、代码骨架、
代表性错题纠正和一份有预算的模拟/小测。不要临时拓展大量课外知识。
最后明确“必须记住 / 必须会做 / 容易丢分”，用户能立刻执行第一块。
每次复测或错题修复后，把受影响的掌握度、错因和复习队列写回工作区的
`study-state.json`；`graduate`、`retest`、`revamp` 等动作沿用本文件已有的
间隔与复习说明计算 `next_review`，不另造一套调度规则。状态文件保存累积进展，
当前回答或 HTML 报告只是即时视图；下一次会话先读取状态，再增量更新，不重建已确认的考试地图。
